# Function Naming

Use these prefixes:

Auth:

- fn*auth*

Tesis:

- fn*tesis*

Reuniones:

- fn*reunion*

Pagos:

- fn*pago*

Documentos:

- fn*documento*

Usuarios:

- fn*usuario*

Asesores:

- fn*asesor*

Mensajes:

- fn*mensaje*

Modulos:

- fn*modulo*

Examples:

- fn_auth_crear_usuario
- fn_auth_login_usuario
- fn_tesis_listar_por_usuario
- fn_reunion_crear
- fn_pago_registrar
- fn_documento_listar_por_tesis
